# RoseMmoon Fashion

**Tagline:** Let Your Beauty Speak.

A standalone fashion storefront starter for RoseMmoon Fashion.

## Files
- `index.html` — homepage and storefront layout
- `style.css` — blush, rose and gold visual system
- `script.js` — sample collection cards and interactive shopping bag

## Before accepting orders
The featured products are visual placeholders, and prices are intentionally marked "Price on request". Add real product photos, names, prices, stock and a confirmed ordering channel before launch. The checkout currently explains that direct ordering needs the store's official WhatsApp number or ordering link.

## Deploy with Netlify
1. Log in to Netlify.
2. Choose **Add new site → Import an existing project**.
3. Connect GitHub and select `rosemmoon-fashion`.
4. Build command: leave blank.
5. Publish directory: `.`
6. Deploy.

No build step is required.
