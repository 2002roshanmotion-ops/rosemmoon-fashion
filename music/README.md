# RoseMoon Music

This folder is for the RoseMoon website's public MP3 tracks.

## Upload the five MP3 files here

Upload the actual MP3 files into this folder using GitHub's **Add file → Upload files** action:

- KATSEYE – Gabriela
- aespa – Black Mamba
- aespa – Next Level
- LILI's FILM – The Movie

Keep the filenames as uploaded. After the MP3 files are committed, their Pages URLs will be:

`https://2002roshanmotion-ops.github.io/rosemmoon-fashion/music/FILE_NAME.mp3`

**Note:** This README creates the `music/` folder only. It does not contain the MP3 audio. The audio files still need to be uploaded to GitHub.
